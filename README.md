# 🛠️ Tukang Ngapak — Website Jasa Bangun & Renovasi Rumah

Selamat datang di repositori **Tukang Ngapak** — platform digital untuk jasa tukang bangunan borongan & harian yang siap membantu proyek rumah Anda, dengan gaya khas Ngapak yang ramah dan jujur!

![Tukang Ngapak Banner](public/banner.jpg) <!-- Ganti dengan gambar banner jika ada -->

---

## 🚀 Fitur Utama

🔨 **Layanan Lengkap:**

- Renovasi rumah, pengecatan, pemasangan keramik, plafon, hingga bangun rumah baru.

📱 **Responsif & Modern:**

- Dibuat dengan framework **Astro** dan **React**, ringan dan cepat di semua perangkat.

🎨 **Antarmuka Bersih & Estetik:**

- Menggunakan **Tailwind CSS** untuk tampilan profesional.

📍 **Navigasi Halus:**

- Navigasi antar halaman menggunakan anchor scroll smooth & drop-down dinamis.

🛒 **Fleksibel:**

- Sistem kerja **Borongan** dan **Harian**, sesuai kebutuhan Anda.

---

## 📦 Tech Stack

| Teknologi    | Keterangan                     |
| ------------ | ------------------------------ |
| Astro        | Static Site Generator          |
| React        | Komponen interaktif            |
| Tailwind CSS | Utility-first styling          |
| TypeScript   | Penulisan kode yang lebih aman |
